# 02 — Khung mô tả theo loại đồ vật

Trích từ mô tả user tự viết ở SOFITEL RE00 (`MATRIX FITFUR-LOOSE`!AJ, 2026-10-22). `<…>` là chỗ thay theo dòng BoQ. Xuống dòng = Alt+Enter (CHAR(10)).

## Ốp vách / ván nền (m²)
- Ván nền dưới hoàn thiện ngoài phạm vi (F085, F086):
  `Tấm nền MDF E1 chống ẩm - dày 17mm Sơn lót` / `Khung xương gỗ sơn lót chống ẩm` / `Không bao gồm:` / `+ <giấy/gương/kim loại theo mã>`
- Vách veneer (F017): `Tấm nền MDF E1 chống ẩm - dày 9mm 1M Sơn lót` / `Tấm hoàn thiện MDF E1 chống ẩm - dày 9mm 1M Veneer <WD-xx> Sơn PU hoàn thiện` / `Khung xương gỗ sơn lót chống ẩm`
- Vách sơn (F084): như trên, thay dòng 2 bằng `… 1M Sơn <PT-xx> hoàn thiện`
- Tấm vách theo kích thước (F010, F014): `Kích thước W<..>xH<..> mm:` / `Tấm hoàn thiện MDF E1 chống ẩm - dày 17mm 1M Veneer <WD-xx>` / `Veneer Tạp Sơn PU hoàn thiện` / `Khung xương gỗ sơn lót chống ẩm.` / (`Không bao gồm Gỗ viền`)
- Vách gương (F082, Nr): `Vách gương tấm nền MDF dày 15mm, sơn lót chống ẩm.` / `Khung xương gỗ.` / `Không bao gồm:` / `+ Gương` / `+ Kim loại`

## Len chân, nẹp, chỉ (m)
- Len gỗ: `Gỗ <Ash|walnut> sơn PU hoàn thiện 18x80mm` (thêm `(màu theo <WD-xx>)` khi nhiều dòng dùng chung block)
- Len sơn: `MDF hoàn thiện <PT-xx> 18x80mm`
- Nẹp/chỉ: `Gỗ Ash sơn PU hoàn thiện.` / `Nẹp <a>x<b>mm.` — nẹp sơn: `Gỗ Ash hoàn thiện <PT-xx>.`
- Nẹp trên kết cấu người khác làm: `… / Không bao gồm: / + Kết cấu bậc trần (khung/thạch cao)` (F083), `+ Tấm thạch cao trần` (F087)

## Vách trang trí, vách TV, vách góc, đầu giường (Nr)
- Vách TV (F029): `Kích thước L<..>xD<..>xH<..> mm :` / `Vách tivi tấm MDF dày 17mm hoàn thiện <PT-xx>.` / `Khung xương gỗ` / `Hậu khu vực tivi MDF 17mm melamine màu đen` / `Không bao gồm:` / `+ Inox MT-02 (ốp và viền kim loại)`
- Vách CNC / vách góc (F031, F052): `Kích thước W..xH.. mm:` / `Tấm nền MDF E1 chống ẩm - dày 17mm 1M Sơn lót` / `Tấm hoàn thiện MDF E1 chống ẩm - dày 3mm` / `Tấm CNC MDF E1 chống ẩm - dày 3mm, sơn 1M <PT-xx>` / `Viền nan gỗ Ash + sơn PU hoàn thiện` / `Khung xương gỗ sơn lót chống ẩm`
- Đầu giường (F035): `Vách tấm trang trí MDF dày 17mm + 12mm hoàn thiện <WD-xx>` / `Viền gỗ Ash trang trí.` / `Khung xương gỗ.` / `Sơn PU hoàn thiện.` / `<vật liệu đặc biệt> Tạm tính <giá>/m2` / `Không bao gồm led, kim loại`

## Tủ (Nr)
- Tủ áo (F038): thùng `Thùng tủ tấm MDF E1 chống ẩm dày 17mm (hông 30mm, hậu 9mm) hoàn thiện <WD-xx>.` / ngăn kéo `Ngăn kéo MDF: mặt ngoài 15mm, thùng 12mm.` / viền, tấm nền vách, khung xương / phụ kiện có mã hãng (`Bản lề Hafele … 315.07.113`, `Ray âm giảm chấn L=450mm … 433.32.074`) / `Bản lề 180 độ tạm tính` / `Không bao gồm:` thanh treo, tay nắm, thiết bị, WC, kim loại, đá
- Minibar (F041): thùng ghi dày từng tấm (`nóc/đáy 25mm, hông 17-35mm, hậu 6mm, đợt/sắn giữa 17mm`) / mặt ngoài `<SP-xx>` / ngăn kéo / phụ kiện / `Không bao gồm:` gia công ngoài, acrylic, inox, kính cường lực, tay nắm, MEP, phụ kiện thoát nhiệt, đá, khung kim loại treo trần (tách hạng mục khác)
- Vanity (F043): `Tấm cemboard 9mm.` / `Khung xương sắt hộp 20x40mm đỡ đá.` / `Tấm nền gương Plywood dày 15mm + sơn lót` / `Không bao gồm:` inox, đá, gương <MR-xx>, viền kim loại gương <MT-xx>
- Bedside liền tường (F044): `Tấm MDF Hoàn thiện <WD-xx>` / `Khung xương gỗ.` / `Sơn PU hoàn thiện.` (+ `Không bao gồm kim loại`)

## Đồ rời (Nr)
- Bàn (L001): `Mặt bàn/chân bàn MDF chống ẩm (mặt dày 35mm) hoàn thiện <WD-xx>` / phần kim loại / tấm đỡ — Console có đá (L014): `Không bao gồm: + Mặt đá … + Kính phủ mặt 6mm`
- Bedside rời (L022): công thức nối chuỗi, có SF da tính từ Chiet tinh: `Kích thước: W..xD..xH.. mm` / `- Hông, đáy ghép hộp xương gỗ thông, MDF E1 chống ẩm, hoàn thiện <WD-xx>` / … / `Không bao gồm:` da bọc (SF/cái, tổng SF), đèn LED, grommet kim loại
- Sofa (L006): `Kích thước: ..mmH` / `- Nền plywood sofa + xương gỗ thông, foam FD40, bọc vải hoàn thiện` / chân / bệ đỡ / gối (tạm tính) / `Không bao gồm:` vải theo mã + số md, ổ cắm
- Ghế (L010, L016): `Ghế gỗ <Oak> sơn PU hoàn thiện: chân/tay vịn/lưng tựa 38x38mm …` / đan / mê ngồi foam / `Không bao gồm: + Vải: <md> + Gối`

## Cửa (Nr) — mục đánh số
- Cửa chống cháy (D01): `Cửa đi 1 cánh EI60 kích thước : W..xD..xH.. mm.` / `1. Cánh cửa dày ..mm: …` / `2. Khuôn cửa ..x.. mm : …` / `3. Nẹp cửa ..` / `4. Đã bao gồm: - Tắc kê nhựa + vít 10x100` / `5. Chưa bao gồm phụ kiện cửa + nhân công lắp đặt (…): - …` / `6. Kết cấu theo BOHO đề xuất`
- Cửa lùa kính (D02), cửa riser (D04–D06), khung cửa không cánh (D13): cùng khung số; riser ghi `Chưa bao gồm: + Hoàn thiện <WC/MR-xx>, phụ kiện cửa, nhân công lắp đặt + Kim loại`
